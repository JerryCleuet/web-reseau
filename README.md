# Réseau & Web : version simplifiée

Site statique HTML/CSS/JavaScript.

## GitHub Pages

1. Placer `index.html`, `styles.css` et `script.js` à la racine du dépôt.
2. Ouvrir `Settings` → `Pages`.
3. Choisir `Deploy from a branch`.
4. Sélectionner `main` et `/(root)`.
5. Enregistrer.

Chaque nouveau `git push` sur `main` republie automatiquement le site.
